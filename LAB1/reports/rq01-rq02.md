# RQ01 e RQ02

Base analisada: 100 repositorios mais populares coletados no GitHub.

## RQ01 - Sistemas populares sao maduros/antigos?

Sim. A idade mediana dos repositorios analisados foi de 3017 dias, aproximadamente 8.27 anos. A media foi de 2797.15 dias, aproximadamente 7.66 anos.

Tambem foi observado que o repositorio mais antigo da amostra possui 6192 dias, enquanto o mais recente possui 133 dias. O primeiro quartil foi de 1200 dias e o terceiro quartil foi de 4255 dias.

Conclusao: os dados indicam que repositorios populares tendem a ser projetos maduros, com varios anos de existencia, embora ainda existam projetos recentes entre os mais estrelados.

| Repositorio | Idade em dias | PRs aceitas |
|---|---:|---:|
| ohmyzsh/ohmyzsh | 6192 | 3650 |
| mrdoob/three.js | 5985 | 15949 |
| rust-lang/rust | 5900 | 73364 |
| d3/d3 | 5797 | 495 |
| ytdl-org/youtube-dl | 5763 | 1646 |

## RQ02 - Sistemas populares recebem muita contribuicao externa?

Sim. A mediana de pull requests aceitas foi de 1254 por repositorio. A media foi de 7282.07, indicando que alguns projetos concentram volumes muito altos de contribuicao.

Dos 100 repositorios analisados, 88 possuem pelo menos 100 pull requests aceitas e 54 possuem pelo menos 1000 pull requests aceitas. Apenas 3 repositorios aparecem com 0 pull requests aceitas.

Conclusao: a maioria dos repositorios populares analisados apresenta forte participacao externa, ainda que exista grande variacao entre os projetos.

| kubernetes/kubernetes | 4448 | 65644 |
| microsoft/vscode | 3995 | 51699 |
