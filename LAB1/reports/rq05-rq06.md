# RQ05 e RQ06

Base analisada: 100 repositórios mais populares coletados no GitHub em 12 de
agosto de 2026.

## RQ05 — Sistemas populares são escritos nas linguagens mais populares?

Resposta direta: sim, na maioria dos casos com linguagem primária identificada.

Métrica usada: linguagem primária retornada por `primaryLanguage.name`.

A referência adotada é o [GitHub Octoverse
2024](https://github.blog/news-insights/octoverse/octoverse-2024/), cujo ranking
apresenta Python, JavaScript, TypeScript, Java, C#, C++, PHP, Shell, C e Go como
as dez linguagens mais usadas no GitHub.

Resultados principais:

- Total de repositórios analisados: 100
- Repositórios com linguagem primária identificada: 87
- Repositórios sem linguagem primária: 13
- Repositórios em uma linguagem do top 10 do Octoverse: 70
- Percentual sobre a amostra completa: 70%
- Percentual entre repositórios com linguagem identificada: 80,46%

| Linguagem primária | Repositórios | Percentual da amostra |
|---|---:|---:|
| Python | 24 | 24% |
| TypeScript | 17 | 17% |
| Sem linguagem identificada | 13 | 13% |
| JavaScript | 10 | 10% |
| C++ | 5 | 5% |
| Rust | 5 | 5% |
| Shell | 5 | 5% |
| Go | 4 | 4% |
| C | 3 | 3% |
| HTML | 3 | 3% |

As demais linguagens somam 11 repositórios: Markdown (3), Jupyter Notebook (2),
Batchfile (1), Dart (1), MDX (1), Java (1), C# (1) e Swift (1).

Discussão: Python, TypeScript e JavaScript concentram 51% de toda a amostra. Ao
considerar somente os repositórios cuja linguagem foi identificada, pouco mais
de 80% utilizam alguma linguagem presente no top 10 do Octoverse 2024. Os 13
casos sem linguagem incluem projetos predominantemente documentais, listas ou
outros conteúdos que não possuem uma linguagem primária detectada.

Conclusão: sistemas populares tendem a utilizar linguagens também populares no
GitHub, embora popularidade do repositório não implique uma única escolha de
tecnologia.

## RQ06 — Sistemas populares possuem alto percentual de issues fechadas?

Resposta direta: sim.

Métrica usada: `closedIssues.totalCount / issues.totalCount`.

Resultados principais:

- Total de repositórios analisados: 100
- Repositórios com razão calculável: 89
- Repositórios sem issues e sem razão calculável: 11
- Mediana de issues fechadas: 92,69%
- Média: 83,50%
- Primeiro quartil: 77,91%
- Terceiro quartil: 97,48%
- Razão mínima: 13,33%
- Razão máxima: 100%
- Repositórios com pelo menos 75% das issues fechadas: 68 de 89
- Repositórios com pelo menos 90% das issues fechadas: 49 de 89

| Repositório | Issues fechadas | Total de issues | Percentual fechado |
|---|---:|---:|---:|
| getify/You-Dont-Know-JS | 947 | 947 | 100% |
| Chalarangelo/30-seconds-of-code | 300 | 300 | 100% |
| microsoft/generative-ai-for-beginners | 244 | 244 | 100% |
| nilbuild/developer-roadmap | 3.183 | 3.184 | 99,97% |
| iptv-org/iptv | 34.136 | 34.152 | 99,95% |

Discussão: a mediana acima de 90% e os 68 repositórios com pelo menos 75% das
issues fechadas indicam forte capacidade de encerramento. Ainda existe variação:
o menor percentual foi 13,33%, e a média menor que a mediana mostra a influência
dos projetos com proporções baixas. Os 11 casos sem issues foram excluídos dos
cálculos da razão para evitar divisão por zero.

Conclusão: na amostra analisada, repositórios populares geralmente apresentam
alto percentual de issues fechadas.
