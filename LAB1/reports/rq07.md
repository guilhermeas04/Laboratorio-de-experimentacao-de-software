# RQ07

Base analisada: 100 repositórios mais populares coletados no GitHub em 12 de
agosto de 2026.

## RQ07 — A linguagem influencia contribuição, releases e atualização?

Pergunta: sistemas escritos em linguagens mais populares recebem mais
contribuição externa, lançam mais releases e são atualizados com mais
frequência?

Resposta direta: parcialmente; os dados mostram diferenças entre linguagens,
mas não sustentam uma relação geral de causa ou uma ordenação consistente.

Métricas usadas:

- contribuição: mediana de Pull Requests aceitas;
- releases: mediana do total de releases;
- atualização: mediana de dias desde `updatedAt`;
- agrupamento: linguagem primária do repositório.

Para reduzir interpretações baseadas em casos isolados, a tabela apresenta
somente linguagens com pelo menos três repositórios na amostra.

| Linguagem | Repositórios | Mediana de PRs aceitas | Média de PRs aceitas | Mediana de releases | Média de releases | Mediana de dias desde atualização |
|---|---:|---:|---:|---:|---:|---:|
| Python | 24 | 1.881,5 | 3.812,3 | 54 | 132,9 | 0 |
| TypeScript | 17 | 6.980 | 11.269,2 | 116 | 191,5 | 0 |
| Sem linguagem identificada | 13 | 317 | 427,2 | 0 | 0,3 | 0 |
| JavaScript | 10 | 1.373 | 7.596,3 | 69 | 197,1 | 0 |
| C++ | 5 | 26.488 | 25.843,4 | 471 | 552,8 | 0 |
| Rust | 5 | 4.197 | 16.764,8 | 39 | 48,4 | 0 |
| Shell | 5 | 222 | 923,4 | 7 | 42,4 | 0 |
| Go | 4 | 3.683,5 | 18.253,2 | 120 | 262,5 | 0 |
| C | 3 | 153 | 2.375 | 52 | 63 | 0 |
| HTML | 3 | 315 | 1.208,3 | 0 | 0 | 0 |
| Markdown | 3 | 157 | 133,7 | 0 | 0 | 0 |

Discussão: TypeScript apresenta medianas maiores que Python e JavaScript tanto
em Pull Requests aceitas quanto em releases. C++ possui as maiores medianas das
duas métricas, embora conte com apenas cinco projetos e não seja a linguagem
mais frequente da amostra. Go também apresenta mediana elevada de releases.
Shell e C, apesar de integrarem o top 10 do Octoverse 2024, mostram valores bem
menores. Portanto, pertencer ao grupo de linguagens mais usadas não determina,
sozinho, maior contribuição ou maior número de releases.

A média é muito superior à mediana em vários grupos, indicando outliers e forte
assimetria. Além disso, grupos pequenos, como C, Go e C++, não devem ser
comparados como se tivessem a mesma representatividade de Python ou TypeScript.

Para atualização, todos os grupos apresentam mediana de 0 dias porque todos os
repositórios tiveram `updatedAt` no dia da coleta. Assim, essa métrica não
permite testar a terceira parte da RQ07. Recomenda-se usar `pushedAt` em uma nova
coleta.

Conclusão: há associação descritiva entre linguagem, Pull Requests aceitas e
releases, mas os resultados não mostram que linguagens mais populares sempre
recebam mais contribuições ou lancem mais releases. A frequência de atualização
permanece inconclusiva com o campo coletado.
