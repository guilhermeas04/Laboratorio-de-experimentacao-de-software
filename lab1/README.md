# Lab 01 - Repositorios populares + Setup do Kanban

Este diretorio concentra os artefatos do Lab01.

## Estrutura

- `01 - LABORATORIO 01 - Repositorios populares + Setup do Kanban.md`: enunciado do laboratorio.
- `code/`: scripts da coleta, consulta GraphQL, validacao e exportacao.
- `data/`: dados gerados pela coleta.
- `docs/`: documentacao do processo, Kanban e configuracoes.
- `reports/`: relatorio final e materiais de apoio.

## Escopo da Lab01S01

- Consulta GraphQL para os 100 repositorios mais populares.
- Coleta dos campos necessarios para as RQs 01 a 07.
- Validacao rapida em amostra de 5 a 10 repositorios por parte de RQ.
- GitHub Projects criado, com colunas e limite de WIP documentados.
