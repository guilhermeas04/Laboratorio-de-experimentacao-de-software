# Documentação do LAB02

Este diretório receberá o desenho do experimento, o protocolo congelado, a
seleção das katas e a tabela de contrabalanceamento. Esses artefatos serão
consolidados nas issues #51 e #52.

O contrato técnico inicial dos dados está documentado no README de `LAB2/` e é
implementado em `LAB2/code/src/lab02/trial_record.py`.
- [`coleta-trials.md`](coleta-trials.md): procedimento operacional do
    cronômetro e regras de encerramento da issue #48.
- [`checklist-pre-trial.md`](checklist-pre-trial.md): checklist técnico
    pré-execução e smoke test da issue #50.
- [`katas.md`](katas.md): seis katas, contrato uniforme e testes congelados da issue #51.
- [`desenho-experimental.md`](desenho-experimental.md): GQM, hipóteses, protocolo, ameaças à validade e contrabalanceamento da issue #52.
- [`../data/design/counterbalancing.csv`](../data/design/counterbalancing.csv): tabela final de execução dos 18 trials.
